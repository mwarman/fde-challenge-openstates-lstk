# PRD Specification - Politician Researcher Prototype

## Requirements

I would like an app to see who the representatives are in the 52 jurisdictions of the United States. I want the latest data — because after elections, or if someone leaves office, this changes. I want to see it by party or by state.

## External Data Sources

### OpenStates API

Note: I have registered and obtained the free-tier API key.

### Additional Information

- Local-running prototype only — no deployment required.
- Use a JS/TS SPA framework (React or Angular) for the frontend.
- Backend language/framework is your choice.
- Total of 30 minutes to plan and implement. Prioritize and be ready to explain what you cut and why.
